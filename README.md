# 🎯 استوديو أغلفة تيك توك والتسويق العقاري الفاخر
### TikTok Real Estate Cover & Marketing Studio PRO
**مخصص لبراند "العمودي للخدمات والوساطة العقارية"**

تطبيق ويب عصري متكامل وسريع (Standalone Web App) مبني بأحدث تقنيات الويب (`React 19` + `Vite` + `Tailwind CSS v4` + `Lucide Icons` + `html-to-image`) لإنتاج أغلفة تيك توك رأسية بدقة فائقة (`1080×1920`) وتوليد كابشنات ورسائل تسويقية فورية.

---

## 🌟 الميزات والمواصفات:

### 1️⃣ محرر الأغلفة الذكي (TikTok Cover Generator - 9:16)
- **دقة فائقة:** تصدير حقيقي بدقة `1080×1920` بدون أي بكسلة.
- **نسخ فوري للحافظة (Copy to Clipboard):** للصق الغلاف مباشرة في برامج المونتاج (CapCut / Premiere).
- **طبقات البلور والفلاتر المتقدمة (Image FX):**
  - تحكم دقيق بتمويه/بلور الخلفية (0 - 25px).
  - طبقات تلوين وتعتيم شفافة (أسود كربوني، بني إسبريسو، رمادي جرافيت، رمادي فضي، أبيض حليبي، كحلي ملكي + مخصص).
  - فلاتر سينمائية سريعة (أبيض وأسود فاخر، دفء سينمائي، معماري بارد، ألوان ساطعة).
  - تدرج تعتيم سفلي ذكي (Smart Vignette) لضمان وضوح النصوص على الصور الساطعة.
- **نظام الخطوط الحر (Multi-Font Typography):**
  - إمكانية رفع أي خط من جهازك (`TTF`, `OTF`, `WOFF`, `WOFF2`).
  - اختيار خط وحجم ولون وسماكة مختلفة لكل سطر وخانة نصية بشكل مستقل تماماً.
  - مكتبة خطوط عربية حديثة مثبتة مسبقاً (Alexandria, IBM Plex Sans, Readex Pro, Almarai, Tajawal, Cairo).
- **تشطيب القوالب (Finish):**
  - **مطفي (Matte / Frosted Glass)**: زجاج مثلج مخملي وظلال ناعمة.
  - **بلمعة ومعدني (Glossy / Metallic Sheen)**: تدرج ضوئي كريستالي ولمعان فاخر.
- **تخطيطات متعددة:** كبسولات عائمة (Pills)، كرت زجاجي فندقي (Glass Card)، شبكة بينتو (Bento Grid)، شريط بانورامي سفلي (Minimal Bar).
- **شعار البراند:** تحكم كامل بموقع الشعار (أعلى اليمين، أعلى اليسار، وسط، أسفل)، وحجمه وشفافيته.
- **واجهة أزرار تيك توك التفاعلية (Safe Zone):** لمعاينة ومطابقة مناطق الأمان على هواتف المستخدمين.

---

### 2️⃣ مولد نصوص السوشيال ميديا (Social Media Copywriter)
- **كابشن تيك توك:** نص مشوق وهاشتاجات عقارية نشطة.
- **بوست إنستغرام وفيسبوك:** منسق بنقاط الجذب والتفاصيل.
- **رسالة واتساب تسويقية:** منسقة مع زر مباشر "إرسال عبر واتساب".
- **نبرة الصوت (Tone of Voice):** (فخم واستثماري، حماسي وسريع، دافئ وعائلي، مقتضب ومباشر).

---

### 3️⃣ سحابة Supabase ومزامنة النماذج (Cloud Sync - Optional)
- يعمل التطبيق تلقائياً وبسرعة البرق محلياً على المتصفح (Offline-first & IndexedDB).
- خيار ربط سحابة Supabase لمزامنة النماذج والخطوط بين أجهزتك وفريق عملك.

## 🌐 النشر على Vercel (Deployment):
1. قم برفع المشروع على مستودع GitHub الخاص بك.
2. توجه إلى [Vercel](https://vercel.com) واختر **Add New Project**.
3. اختر مستودع `tiktok-realestate-studio`.
4. اضغط **Deploy** وسيتم النشر في ثوانٍ معدودة بدون أي إعدادات إضافية!
